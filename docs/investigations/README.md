# Investigations

Dated research notes: data checks, model verification, and review conversations that explain why a change looks the way it does. They are a record, not current documentation; current behavior lives in [frontend/WARP.md](../../frontend/WARP.md) and the files it links.

Each investigation gets its own `YYYY-MM-DD-topic/` folder with a README, any saved data, and the scripts that reproduce its numbers. Saved data must be safe for a public repository: no user ids, owner names, avatars, cookies, or private league data. Label every figure as real, synthetic, or user-reported.
